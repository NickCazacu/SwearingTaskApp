# RoastTodo

Дневной список задач, который ругает тебя, если ты ставишь цели и игнорируешь их.
Фразы генерирует Claude через собственный прокси (Cloudflare Worker). Если сети нет или API упал,
используются локальные шаблоны из `app/src/main/assets/roasts.json`.

```
app/     Android-приложение (Kotlin, Compose, MVVM, Room, DataStore, WorkManager, Hilt, Ktor)
proxy/   Cloudflare Worker: POST /roast → Anthropic Messages API
```

## Как это работает

- **Задачи** привязаны к дню. При первом запуске за день приложение предлагает перенести
  невыполненные вчерашние задачи на сегодня.
- **Уровни ругани**: SOFT / MEDIUM / HARD. Базовый уровень выбирается в настройках.
  Эскалация: +1 ступень, если без выполненных задач ≥ 3 ч, +2 при ≥ 6 ч (не выше HARD).
  «Время без дел» считается от последнего выполнения за сегодня, а если его нет — от создания
  первой задачи дня (`domain/roast/Escalation.kt`, `IdleTime.kt`).
- **Проверки**: `RoastWorker` запускается каждые 1/2/3 ч (настройка). Он молчит, если уведомления
  запрещены, включена пауза на сегодня, сейчас тихие часы или задач нет. Если остались невыполненные
  задачи, присылает одну фразу за интервал. Если всё сделано, раз в день хвалит.
  Логика вынесена в чистую функцию `decideRoast` (`domain/usecase/RoastDecision.kt`).
- **Генерация**: `FallbackRoastGenerator` сначала идёт в `LlmRoastGenerator` (если включено
  «Использовать ИИ» и задан прокси), при любой ошибке переключается на `TemplateRoastGenerator`.
- **Язык (18+)** — три режима в настройках, по умолчанию «Без мата»:
  - «Мат» — матерные фразы (`*_EXPLICIT` в `roasts.json`), достаётся только прокрастинации;
  - «На личности» — мат плюс обзывательства за лень и слабую силу воли (`*_PERSONAL`).
  В любом режиме под запретом внешность, здоровье, семья, национальность, религия, ориентация,
  пол и темы самоповреждения.
- **Дебаг-кнопка** «Поругай меня сейчас» есть только в debug-сборке (Настройки → Отладка).
  Она игнорирует паузу, тихие часы и лимит интервала. Результат и источник (ИИ/шаблон)
  показываются ещё и в снекбаре.

## Запуск приложения

Требования: Android Studio с Android SDK 37, JDK 17+ (подойдёт встроенный JBR из Android Studio).

1. Добавь в `local.properties` (файл уже в `.gitignore`, в git не попадает):
   ```properties
   BASE_URL=https://roast-proxy.<твой-аккаунт>.workers.dev
   APP_TOKEN=<тот же токен, что в секрете APP_TOKEN у воркера>
   ```
   Без этих строк приложение тоже работает, но только на шаблонах.
   Нужен именно HTTPS: Android по умолчанию блокирует cleartext HTTP.
2. Собери и запусти:
   ```bash
   ./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
   ./gradlew testDebugUnitTest      # unit-тесты
   ./gradlew installDebug           # установить на подключённое устройство или эмулятор
   ```
3. На Android 13+ приложение запросит разрешение на уведомления. Если откажешь, на главном экране
   появится баннер с кнопкой «Включить»: она снова покажет системный запрос или откроет настройки
   уведомлений приложения.

Чтобы быстро проверить генерацию и уведомление без ожидания: Настройки → «Поругай меня сейчас».

## Деплой прокси

```bash
cd proxy
npm install
npx wrangler login

# 1. KV для rate limit и мемов: вставь выведенный id в wrangler.toml (kv_namespaces.id)
npx wrangler kv namespace create ROAST_KV

# 2. Секреты (не хранятся в репозитории)
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put APP_TOKEN        # длинная случайная строка, её же пиши в local.properties

# 3. Деплой и стартовый список мемов
npx wrangler deploy
npm run memes:upload
```

Проверка:
```bash
curl -X POST https://roast-proxy.<аккаунт>.workers.dev/roast \
  -H "X-App-Token: <APP_TOKEN>" -H "Content-Type: application/json" \
  -d '{"level":"MEDIUM","tasks":["диплом"],"idleHours":4,"doneCount":1,"totalCount":3}'
# → {"text":"..."}
```

Контракт:

| Ответ | Когда |
|---|---|
| `200 {"text": "..."}` | успех |
| `400` | невалидное тело (`level` ∈ SOFT/MEDIUM/HARD/PRAISE, `tasks` — массив строк, счётчики — целые ≥ 0) |
| `401` | нет или неверный `X-App-Token` |
| `429` | больше `RATE_LIMIT_PER_HOUR` (30) запросов в час на токен |
| `502` | ошибка Anthropic API или пустой ответ; приложение уходит в шаблоны |

Расширения контракта:
- `level: "PRAISE"` — хвалебное уведомление, в этом случае `tasks` содержит выполненные задачи;
- `explicit: true` (необязательное, по умолчанию `false`) — разрешить мат;
- `personal: true` (необязательное, по умолчанию `false`) — разрешить переход на личности, включает `explicit`.

Настройки в `wrangler.toml` → `[vars]`: `MODEL` (по умолчанию `claude-haiku-4-5`) и
`RATE_LIMIT_PER_HOUR`. Локальный запуск: скопируй `.dev.vars.example` в `.dev.vars`
и выполни `npm run dev`.

## Обновление мемов

Мемы лежат в KV под ключом `memes` (JSON-массив строк) и подставляются в системный промпт.
Релиз приложения не нужен:

```bash
cd proxy
# отредактируй memes.json, затем:
npx wrangler kv key put memes --binding=ROAST_KV --remote --path=memes.json
# или короче:
npm run memes:upload
```

Воркер кэширует значение до 5 минут, поэтому новые мемы появляются в ответах с небольшой задержкой.
Если ключ пустой или битый, используется встроенный список из `proxy/src/prompt.ts`.

## Любимые фразы (например, из YouTube)

Ни ИИ, ни прокси сами видео не смотрят и фразы из YouTube не вытаскивают. Но можно добавить свои
любимые фразы вручную: они лежат в KV под ключом `quotes`, и ИИ иногда вставляет их дословно
или обыгрывает. Правила промпта важнее: фразу, которая их нарушает, ИИ не использует.

```bash
cd proxy
# впиши фразы в quotes.json, например: ["фраза один", "фраза два"]
npm run quotes:upload
```

Короткие фразы, до 200 символов каждая, не больше 50 штук. Длинные куски транскриптов
сюда лучше не класть.

## Безопасность

- `ANTHROPIC_API_KEY` есть только в секретах воркера, в приложении его нет.
- `APP_TOKEN` вшивается в APK, и его можно извлечь. Это защита от случайного трафика, а не от
  целенаправленной атаки. Расходы ограничивает rate limit; при утечке смени секрет и пересобери APK.

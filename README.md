# RoastTodo

A daily to-do list that roasts you when you set goals and then ignore them.
Phrases are generated by Claude through your own proxy (a Cloudflare Worker). When there is no
network or the API fails, the app falls back to local templates from
`app/src/main/assets/roasts.json`.

The app UI and all phrases are in Russian.

```
app/     Android app (Kotlin, Compose, MVVM, Room, DataStore, WorkManager, Hilt, Ktor)
proxy/   Cloudflare Worker: POST /roast → Anthropic Messages API
```

## How it works

- **Tasks** belong to a specific day. On the first launch of the day, the app offers to move
  yesterday's unfinished tasks to today.
- **Roast levels**: SOFT / MEDIUM / HARD. The base level is chosen in settings.
  Escalation: +1 level after ≥ 3 h without a completed task, +2 after ≥ 6 h (capped at HARD).
  Idle time is counted from the last completion today or, if there is none, from the creation of
  the day's first task (`domain/roast/Escalation.kt`, `IdleTime.kt`).
- **Checks**: `RoastWorker` runs every 1/2/3 h (configurable). It stays silent when notifications
  are disabled, roasting is paused for today, it is quiet hours, or there are no tasks. If tasks
  are left undone, it sends one phrase per interval. If everything is done, it praises you once
  a day. The logic lives in the pure function `decideRoast` (`domain/usecase/RoastDecision.kt`).
- **Generation**: `FallbackRoastGenerator` tries `LlmRoastGenerator` first (when "Use AI" is on
  and the proxy is configured) and switches to `TemplateRoastGenerator` on any error.
- **Language (18+)**: three modes in settings, "No swearing" by default:
  - "Profanity" — phrases with Russian swearing (`*_EXPLICIT` in `roasts.json`), aimed only at
    procrastination;
  - "Personal" — swearing plus name-calling for laziness and weak willpower (`*_PERSONAL`).
  In every mode, appearance, health, family, ethnicity, religion, sexual orientation, gender and
  self-harm are off-limits.
- **Debug button** "Roast me now" ("Поругай меня сейчас") exists only in debug builds
  (Settings → Debug). It ignores the pause, quiet hours and the interval limit. The result and
  its source (AI or template) are also shown in a snackbar.

## Running the app

Requirements: Android Studio with Android SDK 37, JDK 17+ (the JBR bundled with Android Studio
works).

1. Add to `local.properties` (already in `.gitignore`, never committed):
   ```properties
   BASE_URL=https://roast-proxy.<your-account>.workers.dev
   APP_TOKEN=<the same token as the worker's APP_TOKEN secret>
   ```
   Without these lines the app still works, but with templates only.
   The URL must be HTTPS: Android blocks cleartext HTTP by default.
2. Build and run:
   ```bash
   ./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
   ./gradlew testDebugUnitTest      # unit tests
   ./gradlew installDebug           # install on a connected device or emulator
   ```
3. On Android 13+ the app asks for notification permission. If you deny it, a banner with an
   "Enable" button appears on the main screen: it shows the system prompt again or opens the
   app's notification settings.

To check generation and notifications without waiting: Settings → "Roast me now".

## Deploying the proxy

```bash
cd proxy
npm install
npx wrangler login

# 1. KV for rate limiting and memes: paste the printed id into wrangler.toml (kv_namespaces.id)
npx wrangler kv namespace create ROAST_KV

# 2. Secrets (not stored in the repository)
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put APP_TOKEN        # a long random string; put the same value in local.properties

# 3. Deploy and upload the starter meme list
npx wrangler deploy
npm run memes:upload
```

Check:
```bash
curl -X POST https://roast-proxy.<account>.workers.dev/roast \
  -H "X-App-Token: <APP_TOKEN>" -H "Content-Type: application/json" \
  -d '{"level":"MEDIUM","tasks":["диплом"],"idleHours":4,"doneCount":1,"totalCount":3}'
# → {"text":"..."}
```

Contract:

| Response | When |
|---|---|
| `200 {"text": "..."}` | success |
| `400` | invalid body (`level` ∈ SOFT/MEDIUM/HARD/PRAISE, `tasks` is an array of strings, counters are integers ≥ 0) |
| `401` | missing or wrong `X-App-Token` |
| `429` | more than `RATE_LIMIT_PER_HOUR` (30) requests per hour per token |
| `502` | Anthropic API error or empty completion; the app falls back to templates |

Contract extensions:
- `level: "PRAISE"` — praise notification; `tasks` then contains the completed tasks;
- `explicit: true` (optional, default `false`) — allow swearing;
- `personal: true` (optional, default `false`) — allow name-calling; implies `explicit`.

Settings in `wrangler.toml` → `[vars]`: `MODEL` (default `claude-haiku-4-5`) and
`RATE_LIMIT_PER_HOUR`. To run locally, copy `.dev.vars.example` to `.dev.vars` and run
`npm run dev`.

## Updating memes

Memes are stored in KV under the `memes` key (a JSON array of strings) and inserted into the
system prompt. No app release is needed:

```bash
cd proxy
# edit memes.json, then:
npx wrangler kv key put memes --binding=ROAST_KV --remote --path=memes.json
# or simply:
npm run memes:upload
```

The worker caches the value for up to 5 minutes, so new memes show up in responses with a short
delay. If the key is empty or malformed, the built-in list from `proxy/src/prompt.ts` is used.

## Favourite quotes (e.g. from YouTube)

Neither the AI nor the proxy watches videos or extracts phrases from YouTube. You can add your
favourite phrases manually instead: they live in KV under the `quotes` key, and the AI sometimes
uses them verbatim or plays on them. The prompt rules take priority: a phrase that breaks them
is not used.

```bash
cd proxy
# put phrases into quotes.json, e.g. ["phrase one", "phrase two"]
npm run quotes:upload
```

Keep them short: up to 200 characters each, at most 50 phrases. Avoid long transcript excerpts.

## Security

- `ANTHROPIC_API_KEY` exists only in the worker's secrets; the app never sees it.
- `APP_TOKEN` is embedded in the APK and can be extracted. It protects against casual traffic,
  not a determined attacker. The rate limit caps spending; if the token leaks, rotate the secret
  and rebuild the APK.
